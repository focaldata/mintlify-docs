# Arlo help docs

Source for the Arlo help docs, built on [Mintlify](https://mintlify.com). Pages are MDX files, and navigation is set in `docs.json`.

The site deploys to [docs.focaldata.com](https://docs.focaldata.com) from `main`.

## Making changes

All edits go through pull requests. Mintlify builds a preview for each pull request, and the preview is reviewed before anything is merged to `main`.

To preview locally, install the [Mintlify CLI](https://www.npmjs.com/package/mint) and run `mint dev` from the repo root.
